# footer-group.json registration

`pg-acc-place` is appended to `sections/footer-group.json` on the theme:

```json
"pg_acc_place": { "type": "pg-acc-place", "settings": {} }
```

and added last in `order`, after `pg_mobile`. The full file lives on the theme
(it is theme-editor managed); only the delta is recorded here.
